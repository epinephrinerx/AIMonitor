## R-026 — Settings เรียก registrar

**S1** `SettingsViewModel` ctor เป็น `(SettingsSession session, IReadOnlyList<string>? knownAgents = null, IStartupRegistrar? startupRegistrar = null, string? executablePath = null)` — พารามิเตอร์ใหม่ต่อท้าย ค่าเริ่มต้น null (null = ไม่เรียก registrar, เทสต์เดิมต้องผ่านโดยไม่แก้) · `executablePath` null → `Environment.ProcessPath` ตอนบันทึก · `App.OpenSettings` ส่ง `_startup.StartupRegistrar` (F3) ให้ — หา field/ที่เก็บ `StartupResult` ใน `App` เอง (ถ้าไม่มี ให้เพิ่มการเก็บค่าเดียว ไม่เปลี่ยน signature อื่น)

**S2** ลำดับใน `SaveAsync`: (1) `await _session.UpdateAsync(...)` เหมือนเดิม (ค่าทุกช่องรวม `StartWithWindows` ตามที่ผู้ใช้เลือก) (2) ถ้า `_startupRegistrar` ไม่ null **และ** `_startAtLogin != _original.StartWithWindows` (ค่าเปลี่ยนจากตอนเปิดหน้า) → เปิด: `Register(path, "--tray")` เมื่อ path ไม่ว่าง/whitespace; ปิด: `Unregister()` · ค่าไม่เปลี่ยน → ไม่เรียกอะไรเลย (3) สำเร็จ → พฤติกรรมเดิมต่อ (`_original = _session.Current; RequestClose?.Invoke(true)`)

**S3** registrar throw `InvalidOperationException` / `IOException` / `UnauthorizedAccessException` / `ArgumentException` (ชนิดที่ `XdgAutostartStartupRegistrar` และ `WindowsStartupRegistrar` ใช้) → (ก) ค่าอื่นของ Settings ที่เพิ่งบันทึกคงอยู่ (ข) หาสถานะจริง `actual = _startupRegistrar.GetRegistrationState()` (ถ้า throw หรือ null → ใช้ `_original.StartWithWindows`) แล้ว `await _session.UpdateAsync(s => s with { StartWithWindows = actual })` (ถ้า UpdateAsync นี้ throw `IOException`/`UnauthorizedAccessException` ให้ข้อความรวมในข้อ ค) และตั้ง `StartAtLogin = actual` (ค) `SaveFailed?.Invoke($"Your settings were saved, but \"Open at login\" could not be changed: {exception.Message}")` (ง) **ไม่** เรียก `RequestClose` (หน้าเปิดค้าง ให้ผู้ใช้เห็น) · `_original = _session.Current` ก่อนออก (จะได้ไม่ revert ค่าอื่นเมื่อ Cancel) · exception ชนิดอื่น (เช่น `OutOfMemoryException`) ไม่จับ ปล่อยออก · `IsSaving` กลับเป็น false ใน `finally` เสมอ

**S4** ข้อความ `exception.Message` นำมาแสดงตามที่เป็น (adapter ของ Linux ไม่ใส่ secret) · ไม่ log path

## R-025 — tray availability บน Linux

**T1** เพิ่ม `PackageReference Include="Tmds.DBus.Protocol" Version="0.94.1"` ใน `AIMonitor.Presentation.Avalonia.csproj` (เหตุผล: ใช้ตรวจ StatusNotifierWatcher; เวอร์ชันตรงกับที่ Avalonia ดึงมาแล้ว F8 จึงไม่เพิ่มของใหม่เข้า build) · ไม่แก้ THIRD-PARTY-NOTICES เว้นแต่ license ต่างจาก transitive ที่มีอยู่ — ให้ Writing Owner ตรวจและรายงาน

**T2** ไฟล์ใหม่ `src/AIMonitor.Presentation.Avalonia/MenuBar/TrayAvailability.cs`: `internal static class TrayAvailability` · `static bool Detect()` (ไม่ throw ออกนอกเมธอด) · ตรรกะ: ไม่ใช่ Linux (`OperatingSystem.IsLinux()` false) → `true` ทันที · Linux → `DetectLinux(TimeSpan timeout = 1 s)`: ไม่มี `DBUS_SESSION_BUS_ADDRESS` (null/ว่าง) → `false`; ไม่งั้นเชื่อม session bus ด้วย `Tmds.DBus.Protocol` เรียก `org.freedesktop.DBus.NameHasOwner("org.kde.StatusNotifierWatcher")` ภายใน timeout; ผล true → `true`; false / exception ใด ๆ (รวม timeout, `OperationCanceledException`, `IOException`, `DBusException`) → `false` · ปิด connection ใน `finally` · เมธอดที่รับ `Func<string, bool>`/delegate สำหรับ seam: `internal static bool DetectLinux(Func<bool> hasWatcher)` เพื่อทดสอบได้โดยไม่แตะ D-Bus จริง (delegate throw → false)

**T3** นโยบาย effective: เพิ่ม `internal static AppSettings TrayAvailability.Effective(AppSettings settings, bool available) => available ? settings : settings with { ShowTrayIcon = false }` · `App` เก็บ `bool _trayAvailable` ที่คำนวณครั้งเดียวด้วย `TrayAvailability.Detect()` ก่อนสร้างหน้าต่างหลัก (บรรทัด ~96) · ทุกที่ที่เรียก `TrayPolicy.ShouldStartHidden/ShouldShowTray/ShouldHideOnClose` (F6, สามจุด) ส่ง `Effective(settings, _trayAvailable)` แทน `settings` · **ห้าม** เขียน `Effective` กลับลง settings ที่เก็บ (ค่าที่ผู้ใช้เลือกต้องคงอยู่ เผื่อติดตั้ง extension ภายหลัง)

**T4** `SettingsViewModel` เพิ่ม ctor parameter `bool trayAvailable = true` (ต่อท้ายสุด) และ property `public bool IsTrayAvailable { get; }` · `App.OpenSettings` ส่ง `_trayAvailable` · `SettingsWindow.axaml`: checkbox "Show an item in the menu bar" `IsEnabled="{Binding IsTrayAvailable}"`; checkbox "Closing the window…" `IsEnabled` ต้องเปิดเมื่อ `ShowMenuBarExtra` **และ** `IsTrayAvailable` (ใช้ `MultiBinding` ด้วย `BoolConverters.And` หรือ property ใหม่ `CanMinimizeToMenuBar => ShowMenuBarExtra && IsTrayAvailable` ที่แจ้ง `PropertyChanged` เมื่อ `ShowMenuBarExtra` เปลี่ยน — เลือกแบบ property) · เพิ่ม TextBlock ใต้กลุ่ม: `IsVisible="{Binding !IsTrayAvailable}"` ข้อความ `"No system tray was found on this desktop, so closing the window quits the app. On GNOME, install the AppIndicator extension to use the tray."` (Opacity 0.65, FontSize 12, TextWrapping Wrap เหมือนข้อความเดิม)

**T5** ไม่เปลี่ยนค่า default ของ `AppSettings`, ไม่เปลี่ยน macOS/Windows (T2 คืน true นอก Linux จึง `Effective` เป็น identity)
