①
Latest interval average. Output tokens/s averaged over the last completed interval (3 min by default). Idle intervals read near 0 — honest, and the flat stretches are what make a busy interval legible.
②
Rate meter. Current against the session's own peak, so it self-scales — no invented ceiling. Blue accent, not a status colour: a fast rate is not a warning.
③
Peak reference line. Orange (categorical slot 2) rather than dashed, so it never reads as a gridline. Labelled inline — the only annotation on the plot.
④
Head marker. An 8px dot with a 2px surface ring marks "now" as the trace streams left. The one point that gets a marker.
⑤
Direction. Time flows left→right with the newest interval pinned right. The chips change the summary interval itself (1/3/5/10/15 min, 3 the default), which rescales the x-axis span, not the y-rule.
!
One y-axis only. Tokens/s is the sole measure here; input, output and cache each get their own card or a stacked series, never a second axis.
